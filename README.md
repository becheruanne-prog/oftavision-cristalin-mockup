# Oftavision · Afecțiunile cristalinului — mockup

Mockup pentru categoria „Afecțiunile cristalinului" de pe oftavision.ro.
Export Claude Design, un singur fișier, fără dependențe externe.

## Conținut

`index.html` — mockup complet, 10 pagini din categorie. Textul medical aparține
Dr. Alina Gheorghe și este preluat literal din Batch 2 (Cristalin), iulie 2026.

Fișierul este autonom: stiluri, scripturi și imagini sunt incluse în el.
Se deschide direct în browser, nu are nevoie de server.

## Publicare

Fișierul se numește `index.html`, deci merge servit ca atare de GitHub Pages
sau de orice găzduire statică.

## Reguli de conținut

Textul medical nu se modifică fără acordul Dr. Alina Gheorghe.
Fără prețuri, fără mențiuni despre decontare, fără nume comerciale de aparate,
fără promisiuni de rezultat.
